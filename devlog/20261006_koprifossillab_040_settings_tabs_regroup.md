# koprifossillab 040 — 설정 창의 탭을 다시 묶는다: 설정과 읽는 법 · 소개와 자료 · 판 이력

2026-10-06 · `feature/settings-tabs`

1.2.0(039)의 탭 셋(설정 · 소개와 만든 사람들과 읽는 법 · 자료와 판 이력)을 연구자가 써 보고 다시 묶었다.

- **설정** = 언어·화면 모드·밝기 + **읽는 법** — 둘 다 "이 화면을 어떻게 쓰나" 다. 설정 탭은 창을 열면 바로 보이는 자리라, 화면을 읽는 법도
  거기 있어야 찾기 쉽다
- **소개** = 소개 + 만든 사람들 + **자료** — 무엇을 누가 무엇으로 만들었나. 인용(자료)은 소개의 끝, 만든 사람들 다음
- **판 이력** = 홀로 — 58 판이 길고, 자주 보는 것이 아니다

039 에서 "읽는 법을 설정에 두면 자주 쓰는 단추가 밀린다" 며 버린 묶음을 연구자는 택했다 — 설정 탭의 단추는 셋뿐이고 읽는 법은 접힌 제목
일곱 줄이라 밀리지 않는다. 템플릿의 내용은 그대로 옮기기만 했다. 탭의 이름은 그대로(설정 · 소개 · 판 이력), 탭 하나가 `stab-sources` 에서
`stab-notes` 로 바뀌었다.
