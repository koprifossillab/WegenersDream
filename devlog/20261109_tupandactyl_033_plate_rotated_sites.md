# PBDB 고좌표가 없는 산지를 판으로 돌릴 수 있는 시점에 올린다

2026-11-09 · `feature/plate-rotated-sites`

## 1. 무엇이 빠지고 있었나

PBDB(`pgm=scotese`)가 고좌표를 비운 산지 46,930 곳(산출 41 만)을 016 부터 뺐다(057 §1.3). 원본을 세어 보니(09-30 사본):

- 46,930 곳 모두 `geoplate = "not computable using this model"` — 빈칸이 아니라 PBDB 가 일부러 비운 것이다
- 연대 중간값으로 제4기(<2.58 Ma) 21,441 · 신생대 나머지 15,641 · 중생대 5,217 · 고생대 3,737 · 에디아카라기 이전 894
- 대양 시추 국가 코드(`O2`·`O4` …) 26,663 곳, 그 가운데 2025 년에 한꺼번에 들어온 미화석 산지가 대부분이다

## 2. 다른 연구는 어떻게 하나

- PBDB 는 다른 모델 값으로 빈칸을 채우지 않는다 — 사용자가 따로 계산해 합치라는 입장(paleobiodb/data_service #11)
- **palaeoverse `palaeorotate()`**(Jones et al. 2023, MEE)는 바로 이 빈칸을 메우려고 만든 것이다 — 현재 좌표를 고른 모델로 직접 돌린다
- **rgplates**(Kocsis)는 어느 판 다각형에도 안 드는 점에 NA 를 준다 — 못 놓는 점은 비운다
- Buffan et al. 2023 은 모델 하나를 일관되게 쓰라고 한다. 공통된 금기는 **한 분석 안에서 모델을 섞는 것**

## 3. 정한 것

빼는 기준을 "PBDB 고좌표가 비었나" 에서 **"그 시점에 v19o 로 돌릴 수 있나"** 로 바꾼다. 019 에서 에디아카라기에만 쓰던 규칙을
모든 시점으로 넓힌 것이다. 우리는 이미 모든 산지를 시점마다 v19o 로 돌리므로(017) 모델을 섞지 않는다 — PBDB 고좌표는 판이 없는 시점의
대체값일 뿐이고, 그것마저 없으면 그 시점에서 뺀다(rgplates 의 NA 와 같다).

## 4. 효과

중간값 나이에서 v19o 로 돌릴 수 있는 것은 21,822 곳(46.5%, 산출 19 만):

| 묶음 | 산지 | 돌릴 수 있음 |
|---|---|---|
| 제4기 | 21,441 | 100% |
| 신생대 나머지 | 15,641 | 1.8% |
| 중생대 | 5,217 | 1.4% |
| 고생대 | 3,737 | 0.7% |

- **늘어나는 것은 거의 제4기 산지다** — 0 Ma 시점이 약 8 천 곳에서 3 만 곳으로(대양 시추 미화석이 많다). 다른 시점은 수십 곳
- 제4기 밖에서는 v19o 도 PBDB(Scotese 2021)와 같은 자리에서 판을 못 찾는다 — 같은 계열 모델의 판 다각형 밖이다. 이것은 그대로 빠진다
  (25,108 곳). 다른 모델로 채우지 않는다
- 산출 사본(050)은 지도에 오르는 산지를 따라가므로, 분포 분석에도 같은 산지가 들어간다
- 분류군 찾기(실시간 PBDB)도 고좌표가 빈 산출을 버리지 않고, 산지 파일에 그 시점 나이로 돌린 자리가 있으면 그 좌표로 그린다

## 5. 버린 것

- **제4기만 넣기** — 결과는 거의 같지만 규칙이 하나 더 는다. "판으로 돌릴 수 있으면" 하나로 019 의 특례까지 지운다
- **PBDB 에 `pgs=early|late` 로 다시 물어 채우기** — 판이 없는 것은 나이를 바꿔도 대개 같고, 우리는 어차피 시점 나이로 다시 돌린다
- **다른 모델(Merdith·Müller)로 채우기** — CLAUDE.md "판 모델을 하나로"
