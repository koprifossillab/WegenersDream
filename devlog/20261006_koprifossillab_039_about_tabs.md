# koprifossillab 039 — 설정 창을 탭 셋으로: 설정 · 소개 · 자료와 판 이력

2026-10-06 · `feature/about-tabs`(`feature/mobile-find` 위에서)

연구자가 프로젝트 소개와 누가 기여했는지를 화면과 README 에 두자고 했고, 자리는 GSM(대돌여지도)의 설정 창처럼 창 안의 탭으로 정했다.

## 1. 탭은 셋

처음에는 연구자가 적은 대로 다섯(설정 · 소개와 읽는 법 · 만든 사람들 · 자료 · 판 이력)을 만들었는데, 연구자가 "너무 많다, 기능과 효율로
합칠 것은 합치라" 고 해 셋으로 묶었다.

- **설정** — 언어·화면 모드·밝기. 손으로 바꾸는 것만. 창을 열 때마다 이 탭부터다(자주 여는 까닭이 이것이라)
- **소개** — 소개 → 만든 사람들 → 읽는 법. 셋 다 "읽는 것" 이고, 처음 온 사람이 위에서부터 읽으면 된다
- **자료 · 판 이력** — 출처(인용)와 판마다 바뀐 것. 둘 다 "찾아보는 기록" 이다

버린 묶음 — 읽는 법을 설정에 두기(전처럼): 설정 탭이 길어져 자주 쓰는 단추가 밀린다. 만든 사람들을 자료에 두기: 자료 탭은 인용이라 성격이 다르다.

## 2. 소개와 만든 사람들

소개는 연구자가 준 소속(극지연구소 고생물진화연구실)과 목적(전 세계 화석 기록과 고지구 자료를 통합해 시간에 걸친 생물군의 분포와 다양성
변화를 추적)에, 자료가 무엇이고 좌표를 어떻게 정하는지 한 문단, 이름의 유래 한 줄을 더했다. 만든 사람들은 연구자가 준 이름·맡은 일 그대로 —
최준석(Tupandactyl) 데이터 통합과 수정·기능 추가, 정직한(jikhanjung)·이승찬(wetherilli) 검토와 세부 기능 추가, koprifossillab 총괄. 영어판에서도
이름은 한글 그대로 두고 GitHub 계정을 옆에 둔다 — 로마자 표기를 우리가 지어내지 않는다. 연구실의 영어 이름(Paleontology & Evolution Lab)은
연구자가 확인할 것이다.

같은 내용을 README 의 "소개 · 만든 사람들" 절에도 둔다 — GitHub 에서 저장소를 보는 사람용. 바꿀 때 둘 다 고친다(README 에 적었다).

## 3. 판 이력은 서버가 CHANGELOG.md 를 읽어 그린다

GSM 은 따로 문(`/patch-notes`)을 두고 화면이 JSON 을 받는다. 여기서는 **첫 화면을 그릴 때 템플릿에 넣는다**(`views.patch_notes` →
`viewer/patchnotes.py`). 바깥 사이트(GitHub Pages)는 첫 화면을 Django 로 한 번 구워 내는데(static_site.py), 문을 따로 두면 그 문도 고정 파일로
구워야 한다. 템플릿에 넣으면 굽는 쪽을 고칠 것이 없다. CHANGELOG.md 는 이미지에 함께 들어간다(.dockerignore 에 없다). 58 판이 `<details>` 로
접혀 들어가 첫 화면 HTML 이 40 KB 남짓 는다 — gzip 이면 몇 KB 다.

마크다운은 굵게·코드만 HTML 로 바꾸고 나머지는 이스케이프한다. 링크는 저장소 안의 상대 경로라 화면에서 열리지 않아 글자만 남긴다. 판 머리는
판 번호만 보고 가른다 — 날짜를 빠뜨린 판이 머리로 안 잡혀 통째로 사라지는 일이 GSM 에서 있었다. 판 이력은 한국어만이다(영어판에는 그렇다고 적는다).
