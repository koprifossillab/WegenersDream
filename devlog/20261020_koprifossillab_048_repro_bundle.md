## 2. 재현의 한계를 숨기지 않는다

지도의 산지는 가공물(그 주의 PBDB 사본, 백업에 남는다 — docs/백업.md)이라 `manifest.json` 의 sha256 으로 그 사본을 찾을 수 있다. 그러나 분류군
찾기·분포는 **실시간 PBDB** 다. 같은 주소로 다시 물어도 같은 수가 나온다는 보장이 없다 — README 에 그대로 적었다. PBDB 에 물은 주소는
브라우저의 `performance` 자원 목록에서 PBDB 로 간 것만 모은다 — 코드의 질의를 다시 짜 맞추지 않으니 실제로 물은 것과 어긋날 일이 없다.

## 3. zip 은 손으로

글자 파일 몇 개라 라이브러리(JSZip 등)를 들이지 않고 `analysis.js` 에 압축 없는(STORE) zip 쓰개를 두었다 — CRC32 와 머리 셋, 60 줄. 이름은
UTF-8(일반 목적 비트 11). JS 시험은 CRC32("hello")와 zip 의 머리·끝을, 확인은 브라우저에서 만든 zip 을 파이썬 `zipfile` 로 열어
`testzip()`(CRC) 통과와 한글 이름을 봤다.

확인: 로컬 Lystrosaurus 250 Ma — 묶음 25.8 KB, 다섯 파일. `series.csv` 의 265 Ma 줄은 산출 1·몫 0.402·몬테카를로 0–1.
